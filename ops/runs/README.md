# דוחות ריצה של מרלוג

כל ריצה של `scripts/daily-refresh.sh` (היומית ב-05:55 והניסיון החוזר `--only-failed` כל שעתיים) מוסיפה
כאן את המסקנות שלה ודוחפת אותן לענף. כך אפשר לקרוא מה קרה מכל מחשב ב-`git pull`, בלי גישה ללוג המלא
שנשאר רק על המק ב-`~/Library/Logs/salhacham/<תאריך>.log`.

- `ops/runs/<YYYY-MM-DD>.md` - קובץ ליום, סעיף לכל ריצה: שעה, סוג (`daily` / `retry`), ותוצאה.
- כל סעיף מכיל את השורות שאדם היה רוצה לקרוא: כמה רשתות ירדו ומי נכשלה, משכי השלבים, מה פורסם
  (`pushed <hash>`) או למה לא, כיסוי הסניפים ב-DuckDB, ואזהרות ושגיאות.
- הדוח נכתב ונדחף **גם בריצה שלא פרסמה כלום** - בדיוק הריצה ששווה לקרוא עליה.
- ה-commit של הדוח נפרד מ-commit הנתונים, בהודעה `ops: <mode> run report <תאריך>`.

מה לא כאן: הלוג המלא (מאות שורות לכל ריצה, כולל פלט של כל רשת), קובצי המחירים הגולמיים, ובסיס
ה-DuckDB. אלה חיים על המק בלבד. ההסבר על הריצה עצמה, התזמון והתקלות הנפוצות: `docs/RUNNER-MAC.md`.
