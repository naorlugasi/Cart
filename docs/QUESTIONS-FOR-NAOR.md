## 12.10 - מסבב העצים (סוננט בנה, אופוס פיקח)

**נענו 12.10 (נאור):** פאנטה וספרייט = קו איקוני = עלה; עוגת שוקולד = עלה; "עוגיות אוראו" → עלה אוראו (כמו קינדר); תחליף מהמשפחה עם הסתייגות = כן; פחם למנגל = עלה; מרקי שקית ומרקים מוכנים = עלים לפי צורה. מחלקות גבוליות נענו 12.10: חטיף גבינה נשאר בחטיפים, רוגלך ארוז נשאר בחטיפים, מים מזוקקים → ניקיון, טושונקה → שימורים. פתוח: רמה רביעית (`group`), הוסבר ומחכה.


1. **מה הוא עלה ומה הוא טעם, שלוש סתירות שהביקורות השאירו לך:** פאנטה וספרייט הם עלים (soda-orange, soda-lemon-lime) אבל שוופס תפוזים הוא "סודה בטעמים" עם טעם כסוג; עוגת שוקולד / דבש / גבינה נשארו עלים (מפורסמים) בזמן שעוגת תפוזים הפכה ל"עוגה בחושה" עם טעם כסוג; cookies-oreo מחריג "עוגי" ולכן "עוגיות אוראו" לעולם לא מגיע לעלה של אוראו, בניגוד לקינדר.
2. **רמה רביעית בעץ:** הבדיקה conceptFamilies כופה שכל המושגים עם אותה קידומת (yogurt-*, cream-*, beef-*) ישבו במשפחה אחת, ולכן בקר → נתחים / פנימיות / טחון, או גבינת שמנת מול רוטב שמנת, לא ניתנים לביטוי. ההצעה: לאכוף את כלל הקידומת רק על מושג בלי family מפורש, ולהוסיף שדה תוספתי `group` (מחלקה → קבוצה → משפחה → מושג). היום הסוכנים דחסו את הקבוצה לתוך שם המשפחה ("גבינות / גאודה"), וזה מה שיוצג בשבבים.
3. **תחליף ברמת המשפחה:** המנוע תומך בהצעת תחליף מהמשפחה (tier: family) כששום מוצר בעלה לא נמכר ברשת, אבל families ב-rules.json מכיל משפחה אחת, אז זה כמעט לא קורה. אחרי שהעלים התפצלו (עוגיות לשמונה, סוכריות לשישה) "חסר בלי תחליף" בסימולטור עלה מ-20.3% ל-21.2% בדיוק מהסיבה הזאת. לחבר את המשפחות שבקובצי המושגים לשכבת התחליפים = התחליף עולה בעץ, עם הסתייגות "מאותה משפחה".
4. **מרקי שקית ומרקים מוכנים** (מרק עשיר, מרק היום) נשארו בלי מושג; ציר "זן" לטונה (בהירה / לבנה של ORTIZ); אפונה יבשה מול שימורים.
5. **מחלקות לפי מדפי הרשתות, שלוש שאלות:** רוגלך ארוז (חטיפים או מאפים?), "חטיף גבינה" (סירוק רוסי: חלב או חטיפים?), מים מזוקקים (משקאות או ניקיון?), tushonka (בשר או שימורים?).
6. **cocktail-rtd מול alcoholic-mixed-drink** כפולים; **juice-grape** רק "תירוש" ו"מיץ ענבים" נופל ל-juice-mixed.
7. **פחם למנגל** (נשאר פתוח מ-11.10), **מולטיקט** ועוד מזון חיות במחלקת בשר (categorize.js).
8. **מנוע, שלושה תיקונים שהביקורות ניסחו במדויק:** FILLING_PHRASE מוחק "קרם ידיים/פנים/יום" (18 מושגים חיים היום על flavourIsIdentity כעקיפה); none לא מעוגן לגבול מילה ("ליימ" בתוך "מינרליים"); כלל "הספציפי גובר" במקום 30+ מילות חסימה בכל מושג כללי.
